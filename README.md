# 理性瘋狗 Discord 工具 v2.2.1

一個功能強大的 Discord Token 管理與自動化工具。

---

⚠️ 警告
使用本工具違反 Discord 使用條款，可能導致帳號被永久封禁，請自行承擔風險。

---

✨ 主要功能
- 漂亮的動態 RGB 彩色介面
- 多頁面功能選單（共 4 頁）
- Token 批量檢查、上線、加入/退出伺服器
- 多種轟炸功能（訊息、表情、@everyone、討論串等）
- 伺服器管理（創建頻道、停權、蒐集等）
- Cwelium 優化功能
- 本地帳號系統 + Discord 備份

---

🚀 使用方法

1. 安裝依賴套件：
   pip install colorama aiohttp requests

2. 將 Token 放入 token.txt（一行一個）

3. 執行程式：
   token控制器面板exe

---

📁 重要檔案
- token.txt       → 存放 Token
- users.json      → 本地帳號資料
- invites.txt     → 邀請連結

---

📋 功能概覽
第一頁：Token 檢查、上線、各種轟炸功能
第二頁：頻道管理、成員蒐集、狀態輪播
第三頁：Cwelium 優化功能
第四頁：其他進階功能

---

🛡️ 使用建議
- 建議搭配代理使用
- 降低操作頻率
- 不要使用主帳號
